# react-labs

Лабораторні роботи з курсу «Розробка вебзастосунків на React».

- `lab-1/` — налаштування середовища: Node.js, Vite, ESLint, Prettier,
  картка «Про мене».
- `lab-2/` — компоненти, дерево компонентів і пропси: сторінка «Команда
  проєкту».
- `lab-3/` — рефакторинг за деревом компонентів (Thinking in React):
  сторінка «Меню кав'ярні».
- `lab-4/` — стан і ефекти: пошук, прапорець «Лише в наявності» та
  збереження фільтрів у `localStorage`.
- `lab-5/` — події, контрольовані й неконтрольовані компоненти: форма
  бронювання столика.

## Команди

Залежності встановлюються один раз у корені репозиторію:

```bash
npm install
```

Далі команди виконуються в теці потрібної лабораторної:

```bash
cd lab-1
npm run dev
npm run lint
npm run format:check
npm run build
```

Те саме для `lab-2/`, `lab-3/`, `lab-4/` і `lab-5/`.
